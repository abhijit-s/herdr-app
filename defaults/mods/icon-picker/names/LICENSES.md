# Icon names

- `glyphs.json`: the Symbols Nerd Font's glyph names, from Nerd Fonts' `glyphnames.json` at the font's release (https://github.com/ryanoasis/nerd-fonts), MIT. Full notice: [LICENSE-NerdFonts.txt](LICENSE-NerdFonts.txt).
- `emoji.json`: emoji names, keywords and groups from emojibase-data's `en/compact.json` (https://github.com/milesj/emojibase), MIT, full notice: [LICENSE-emojibase.txt](LICENSE-emojibase.txt). Its names and keywords come from Unicode CLDR (https://cldr.unicode.org), Unicode License v3.

`scripts/icon-names.ts` in the Herdr app's repository builds both. The release's THIRD-PARTY-NOTICES includes these notices and the Unicode License.
