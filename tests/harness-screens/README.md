# Harness screen fixtures

Screens for the rules in `defaults/harnesses`, copied unchanged from tuios's `internal/harness/testdata/screens` (https://github.com/Gaurav-Gosain/tuios/tree/b58d85aa1254becefd598cc2640af126a2e49e98, MIT, see `defaults/harnesses/LICENSE-tuios.txt`). Each names its harness and the state its rules must find; `src/harness_tests.rs` checks every one and that every rule decides at least one.
